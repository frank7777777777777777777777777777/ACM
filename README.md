# 矩阵取数游戏 - 完整解决方案

## 问题描述

师师经常跟同学玩一个矩阵取数游戏：对于一个给定的 n × m 的矩阵，矩阵中的每个元素 aᵢⱼ 均为非负整数。

### 游戏规则

1. **取数规则**：每次取数时须从每行各取走一个元素，共 n 个。经过 m 次后取完矩阵内所有元素
2. **位置限制**：每次取走的各个元素只能是该元素所在行的行首或行尾
3. **得分计算**：每次取数都有一个得分值，为每行取数的得分之和，每行取数的得分 = 被取走的元素值 × 2ⁱ，其中 i 表示第 i 次取数（从 1 开始编号）
4. **目标**：游戏结束总得分为 m 次取数得分之和，求最大总得分

### 输入格式
- 第一行：两个用空格隔开的整数 n 和 m
- 第 2 ~ n + 1 行：n × m 矩阵，其中每行有 m 个用单个空格隔开的非负整数

### 输出格式
- 输出文件只包含 1 行，为一个整数，即输入矩阵取数后的最大得分

### 数据范围
- 对于 60% 的数据，满足 1 ≤ n, m ≤ 30，容量不超过 10¹⁶
- 对于 100% 的数据，满足 1 ≤ n, m ≤ 80，0 ≤ aᵢⱼ ≤ 1000

## 算法分析

### 第一步：问题难点分析

1. **状态空间爆炸**：
   - 每行有 m 个元素，可以从左或右取，总共有 2^m 种取法
   - n 行就有 (2^m)^n = 2^(mn) 种组合
   - 对于 m=30 的情况，这是不可接受的复杂度

2. **权重递增特性**：
   - 后取的数权重更大（2^i），这意味着我们应该把大的数留到后面
   - 但是每行的最优策略可能不同，需要全局考虑

3. **多维决策问题**：
   - 每轮需要同时决定 n 行的取数位置（左端或右端）
   - 这些决策之间相互影响，因为权重是共享的

### 第二步：相关算法研究

通过研究相关文献和算法，发现了以下关键技术：

1. **区间动态规划**：
   - 经典的"从两端取数的最优策略"问题
   - 状态转移：`dp[i][j] = max(arr[i] + min(dp[i+2][j], dp[i+1][j-1]), arr[j] + min(dp[i+1][j-1], dp[i][j-2]))`

2. **状态压缩DP**：
   - 使用位掩码表示每行的取数状态
   - 记忆化搜索避免重复计算

3. **博弈论和矩阵游戏**：
   - 多人博弈的最优策略计算
   - 线性规划求解混合策略

### 第三步：最终算法设计

基于研究结果，设计了以下算法：

#### 核心思想
- **状态表示**：使用每行的左右边界 (left, right) 表示当前状态
- **状态转移**：枚举每行取左端或右端的所有组合（2^n 种）
- **记忆化优化**：使用 LRU 缓存避免重复计算

#### 算法复杂度
- **时间复杂度**：O(m × 2^n × n)
- **空间复杂度**：O(2^(n×m))

#### 伪代码
```python
def solve(matrix):
    @lru_cache(maxsize=None)
    def dp(state, round_num):
        if round_num > m:
            return 0
        
        max_score = 0
        weight = 2^round_num
        
        for mask in range(2^n):  # 枚举所有取数组合
            current_score = 0
            new_state = []
            
            for i in range(n):
                left, right = state[i]
                if mask & (1 << i):  # 取右端
                    current_score += matrix[i][right] * weight
                    new_state.append((left, right - 1))
                else:  # 取左端
                    current_score += matrix[i][left] * weight
                    new_state.append((left + 1, right))
            
            future_score = dp(tuple(new_state), round_num + 1)
            max_score = max(max_score, current_score + future_score)
        
        return max_score
    
    initial_state = tuple((0, m-1) for _ in range(n))
    return dp(initial_state, 1)
```
