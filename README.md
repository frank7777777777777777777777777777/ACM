# 传纸条问题解决方案

## 问题概述

这是一个经典的动态规划问题，要求在m×n网格中找到两条不相交的路径，使得路径上数值之和最大。

## 文件说明

### 核心实现
- `paper_passing.cpp` - C++标准实现
- `paper_passing_optimized.cpp` - C++空间优化版本
- `paper_passing.py` - Python详细注释版本

### 测试和分析
- `test_input.txt` - 题目给出的测试用例
- `test_cases.py` - 多个测试用例验证
- `algorithm_analysis.md` - 详细算法分析文档

## 算法核心思想

### 问题转化
将"去程+回程"问题转化为"两个人同时从起点出发"问题：
- 两个人都从(1,1)出发到(m,n)
- 每步可以选择向右或向下
- 两人不能同时占据同一位置

### 状态设计
使用三维DP：`dp[step][i1][i2]`
- `step`: 当前步数
- `i1`, `i2`: 两人当前行坐标
- 列坐标通过公式计算：`j = step + 2 - i`

## 复杂度分析

- **时间复杂度**: O((m+n) × m²)
- **空间复杂度**: O(m²) (优化版本)
- **适用范围**: m,n ≤ 50 (题目约束)

## 算法特点

### 优势
1. 时间复杂度合理，满足题目要求
2. 算法思路清晰，易于理解
3. 可进行空间优化
4. 具有良好的扩展性

### 关键技巧
1. 问题转化：将双向路径转化为同向双路径
2. 维度压缩：利用步数相等的性质减少状态维度
3. 滚动数组：优化空间复杂度

## 测试结果

所有测试用例均通过验证：
- ✓ 题目样例 (3×3矩阵) → 输出34
- ✓ 最小规模 (2×2矩阵) → 输出3
- ✓ 边界情况 (单行/单列) → 正确处理
- ✓ 特殊情况 (全零矩阵) → 输出0

## 算法应用

这个算法模式适用于：
- 网格路径优化问题
- 多路径不相交问题
- 资源分配优化问题
- 竞赛编程中的经典DP问题

1. **路径数量扩展**: 可以扩展到k条不相交路径

3. **目标函数变化**: 可以改为最小化或其他优化目标
