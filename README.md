# 矩阵取数游戏 - NOIP 2007

## 问题描述

对于一个给定的 n×m 的矩阵，矩阵中的每个元素均为非负整数。游戏规则如下：

1. 每次取数时须从每行各取走一个元素，共 n 个。经过 m 次后取完矩阵内所有元素；
2. 每次取走的各个元素只能是该元素所在行的行首或行尾；
3. 每次取数都有一个得分值，为每行取数的得分之和，每行取数的得分 = 被取走的元素值 × 2^k，其中 k 表示第 k 次取数（从 1 开始编号）；
4. 游戏结束总得分为 m 次取数得分之和。

求取数后的最大得分。

## 算法分析

### 关键洞察
- **每行独立**：每行的取数策略相互独立，可以分别求解后相加
- **区间DP**：对每一行，这是一个经典的区间动态规划问题

### 算法思路
1. 对每一行单独处理，使用区间DP
2. `dp[i][j]` 表示取完区间 `[i,j]` 的最大得分
3. 状态转移方程：
   ```
   dp[i][j] = max(
       dp[i+1][j] + matrix[row][i] * 2^(m-length+1),
       dp[i][j-1] + matrix[row][j] * 2^(m-length+1)
   )
   ```
4. 最终答案为所有行的最优得分之和

### 复杂度分析
- **时间复杂度**：O(n × m³)
- **空间复杂度**：O(m²)
- **数值范围**：需要高精度计算（2^80 约为 25 位数）

## 测试用例

### 样例输入
```
2 3
1 2 3
3 4 2
```

### 样例输出
```
82
```

### 解释
- 第一行 [1,2,3] 最优策略：取1(2^1) → 取2(2^2) → 取3(2^3) = 2+8+24 = 34
- 第二行 [3,4,2] 最优策略：取2(2^1) → 取3(2^2) → 取4(2^3) = 4+12+32 = 48
- 总分：34 + 48 = 82

## 算法要点

1. **区间DP的本质**：从两端取数，每次决策影响后续状态
2. **权重递增特性**：后取的数权重更大（2^k），需要仔细规划
3. **独立性原理**：行与行之间无关联，可以分别优化
4. **高精度需求**：2^80 是一个25位数，必须使用高精度算法

这是一道经典的动态规划题目，很好地考查了区间DP的思想和高精度计算的处理。
